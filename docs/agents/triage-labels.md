# Triage Labels

The five canonical triage roles and their labels:

| Role | Label | Description |
|------|-------|-------------|
| Needs evaluation | `needs-triage` | Maintainer needs to evaluate |
| Waiting on reporter | `needs-info` | Waiting on reporter for more info |
| Ready for agent | `ready-for-agent` | Fully specified, AFK agent can implement |
| Ready for human | `ready-for-human` | Needs human implementation |
| Won't fix | `wontfix` | Will not be actioned |

Labels are managed via `bd label` command.
